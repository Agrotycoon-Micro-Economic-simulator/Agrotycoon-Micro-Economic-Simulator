# 🌾 Agrotycoon: Micro Economic Simulator

**Simulasi Ekonomi Mikro Berbasis Data Nyata Indonesia**

Agrotycoon adalah game simulasi ekonomi dan pertanian berbasis web yang dirancang untuk memberikan pengalaman manajemen bisnis yang realistis, edukatif, dan adiktif. Dimulai dari lahan warisan dengan 10 pohon kelapa, pemain belajar mengelola rantai pasok, mulai dari panen, pengolahan nilai tambah (Es Kelapa), hingga manajemen keuangan rumah tangga, berdasarkan data HPP dan harga pasar riil Indonesia.

## 🎯 Fitur Utama (MVP)
- **Realistis & Edukatif**: Data harga komoditas, HPP, dan biaya hidup berdasarkan data riil.
- **Learning Gate**: Pemain wajib menyelesaikan modul pembelajaran sebelum memanen.
- **Simulasi Kehidupan**: Manajemen biaya hidup harian yang memaksa pemain untuk tidak sekadar menjual bahan mentah ke tengkulak.

## 🚀 Cara Menjalankan
1. Clone repositori ini atau download sebagai ZIP.
2. Buka file `index.html` langsung di browser (Chrome/Firefox/Safari).
