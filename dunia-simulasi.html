Status engine

Parameter skenario: EKSPERIMENTAL. Engine awal sudah berjalan secara deterministik per seed, tetapi probabilitas bencana dan besaran dampak belum dikalibrasi dari berkas historis mentah. Harga di halaman ini berupa indeks simulasi (×), bukan harga Rupiah yang diklaim sebagai data nyata.

Buka dari permainan untuk melihat keadaan simulasi tersimpan. Jika halaman dibuka langsung, data sesi game browser mungkin tidak tersedia.

Catatan kalibrasi data

Data bencana nyata digunakan untuk memperkirakan frekuensi dan sebaran risiko; data harga historis digunakan untuk kalibrasi volatilitas dan hubungan stok-harga. Skenario historis tidak otomatis diputar ulang di setiap game.

  • BNPB DIBI — riwayat kejadian bencana
  • Satu Data Bencana Indonesia — dataset historis
  • Bapanas — harga pangan bulanan tingkat konsumen provinsi
  • BPS — harga konsumen perdesaan bulanan 2025

Perbedaan level pasar (produsen, grosir, konsumen), satuan, dan periode wajib dipertahankan saat impor.
