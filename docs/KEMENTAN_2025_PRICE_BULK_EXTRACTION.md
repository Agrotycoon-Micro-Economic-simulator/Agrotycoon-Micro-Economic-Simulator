## Scope and extraction method

The 185-page official PDF was accessible as searchable text in this pass. Table 2.1 (printed p.19; PDF p.45) gives national producer-price annual averages for 26 agricultural commodities, with 2021–2024 values and 2023–2024 growth. The series is BPS-sourced as stated in the table. Table 1.1 (printed p.3; PDF p.29) provides annual paddy prices by stage for 2021–2025, where 2025 is January–November only. This is a historical producer-price tranche, not the still-blocked BPS monthly 2025 publication PDF.

All prices below are nominal source values; unit, stage and product form are preserved. These are not complete economic models and are not runtime-approved parameters. For each table 2.1 commodity, the listed four values correspond to 2021, 2022, 2023, 2024 respectively. Source table heading says 2020–2024, but its displayed data columns in the extracted table begin at 2021; no 2020 value is inferred or inserted.

## Data-quality gates

- Table 2.1 contains 26 commodity rows × 4 displayed years = 104 exact annual producer-price observations. Table 1.1 contains 26 non-dash annual price cells across farmer/mill stage and GKP/GKG/outside-quality categories. Total exact numeric price cells in this tranche: 130.
- The 2024 values are the latest values in Table 2.1; they must not be described as 2025 or 2026 prices. Table 1.1 has limited 2025 Jan–Nov annual averages for GKP/GKG only as shown.
- Generic labels do not resolve cultivar/grade or processing node: “ayam” is liveweight, not meat; “kelapa tua” is per nut and is not split into Kelapa Super/Biasa; “kopi robusta” producer form must be reconciled with cherry/green bean; “karet getah tebal” must be reconciled with latex grade and the SEP latex table. No unit conversions are inferred.
- Table 2.1 contains producer prices only, not matched production cost, yield, loss, capital, mortality, rejection or logistics. It cannot clear any row's full unit-economics gate.
- These 26 commodity categories overlap with, but do not equal, the owner's 60-row inventory. They are source-category observations, not 26 fully verified owner rows.
- No runtime files, commodity IDs, owner-approved coconut benchmark, or game balance values were changed. Documentation/research only; no tests run.
